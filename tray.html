Carregue as três exportações do Signus. O processamento acontece neste navegador, sem consumir IA. Os produtos serão gerados ocultos e inativos para revisão.

2. Preço e estoque

Informe valores padrão para o lote ou carregue uma planilha com as colunas SKU, Preço, Estoque. Valores por SKU têm prioridade. Estoque zero é aceito; campo vazio exige preenchimento.

3. Imagens por código

Use uma lista de nomes exportada do bucket ou selecione as fotos locais para obter os nomes. As fotos não são enviadas. Os sufixos são preservados: código.jpg, código_1.jpg, código_2.jpg…

As URLs são montadas somente para nomes presentes no inventário. O servidor precisa permitir acesso público; esta tela não confirma a disponibilidade de cada URL.

Antes de importar

  1. Cadastre os atributos técnicos e vincule-os à categoria principal.
  2. Importe produtos, depois variações e por último características.
  3. Use os modelos existentes quando as colunas coincidirem. O relatório informa quando criar outro modelo técnico.
  4. Confira fotos, pesos, preços e saldos antes de ativar os produtos.

Avisos e preparação das categorias



Perfil atual: até 100 variações, um eixo variável e sete imagens por SKU. Grupos com múltiplos eixos ou categorias de quatro níveis exigem revisão explícita e são bloqueados. Nenhum arquivo é importado automaticamente na loja.
