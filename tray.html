    Avisos do lote
    Onde importar cada arquivo na Tray

    No painel Tray, acesse Aplicativos → Meus aplicativos → Importação de Dados via Excel. Extraia o ZIP e importe os XLSX separadamente, nesta ordem:

    1. 01_Produtos.xlsx → quadro Produtos → Importar Produtos de um Modelo → modelo 133457 — Top Click - Produtos Signus v2 - Categorias por ID. Aguarde concluir.
    2. 02_Variacoes.xlsx → quadro Variações → Importar Variações de um Modelo → modelo 24682. Só aparece quando há variações.
    3. 03_Caracteristicas.xlsx → quadro Características → Importar Características de um Modelo. Confira o modelo indicado abaixo: os atributos e a ordem das colunas devem coincidir.

    Também é possível abrir o importador por Produtos → Lista de produtos → Mais opções → Importar produtos do Excel.

    Nos modelos: dados a partir da linha 2, coluna A; para itens ausentes do arquivo, escolha Nenhuma ação. Aguarde cada processamento e confira os erros antes de seguir.

    LEIA-ANTES.txt e relatorio.json são apenas para consulta. O Modelo_Preco_Estoque.xlsx preenchido volta ao agente, não vai diretamente para a Tray. Este fluxo gera o cadastro completo; não é uma atualização isolada de preço/estoque de produtos já ativos.

    A referência do pai agora usa seu código comercial. No piloto: agrupamento Signus 54423 → referência 11422529. Para lotes antigos, corrija a referência do pai existente antes de reenviar, evitando duplicar o cadastro. O piloto ID Tray 29 já foi corrigido.

    Categorias por ID: gere novamente os arquivos e use somente o modelo v2 (133457). O modelo v1 (133271) trabalha com nomes e pode criar categorias duplicadas. Categorias sem vínculo cadastrado impedem a exportação. F e G são reservadas e não são importadas.

    As características devem estar cadastradas e vinculadas à categoria na Tray.
